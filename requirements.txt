# AnalyseIt - runtime requirements. Python 3.11+.
#
# This is what Streamlit Community Cloud installs (it only ever reads a file
# named requirements.txt), and all you need to run the app locally. It has no
# PyTorch: ChromaDB bundles the all-MiniLM-L6-v2 model as ONNX, and
# rag_engine.py picks that backend automatically. Its vectors match the
# sentence-transformers backend to within ~2e-7 and give identical retrieval
# rankings (`python eval_retrieval.py --compare`).
#
# For the test suite and the sentence-transformers backend:
#   pip install -r requirements-dev.txt
#
# Exact pins: the set the test suite and eval_retrieval.py pass on. Upgrade
# deliberately - bump a pin, re-run `pytest` and `python eval_retrieval.py`.
# numpy and scipy are the newest releases that still support Python 3.11.
